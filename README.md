# Каталог Справочника АЭ

Открытая база приложения «Справочник АЭ» ООО «Автоэлектроника».

В файлах **нет цен**. Это те же позиции, что на [ae69.ru](https://www.ae69.ru).

Телефоны с приложением версии 2.4 и новее сами забирают `catalog.db`,
когда номер `dataVersion` в манифесте становится больше, чем на устройстве.

Сотрудникам ничего обновлять не нужно.
